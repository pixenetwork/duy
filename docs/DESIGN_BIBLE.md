# Pixel Design Bible v0.1

## Identity

Pixel Network uses a premium, futuristic visual language built around an angular PN monogram, orbital ring geometry, obsidian glass, chrome edges, electric-blue illumination, and restrained violet energy accents.

## Core palette

- Obsidian 950: `#05070D`
- Obsidian 900: `#090D16`
- Panel: `rgba(13, 19, 32, 0.88)`
- Chrome: `#DCE7F6`
- Electric Blue: `#29A8FF`
- White Core: `#F7FBFF`
- Violet Edge: `#8A5CFF`
- Success: `#31E6C2`
- Warning: `#FFBF57`
- Danger: `#FF4E6A`

## Typography

- Display/headings: a geometric extended face matching the approved brand assets.
- Body/UI: Inter, Geist, or a similarly readable sans-serif.
- Numeric data: tabular numerals.
- Uppercase is reserved for short labels, navigation, and system states—not paragraphs.

## Signature geometry

- Use partial orbital arcs and asymmetric chamfers inspired by the PN emblem.
- Avoid generic rounded rectangles everywhere.
- Primary panels should combine one sweeping corner with one controlled angular cut.

## Material

- Obsidian glass surface
- Fine brushed-metal edge
- Blue-white-violet energy line
- Restrained bloom; text must remain crisp
- Depth created through border light and layering, not heavy drop shadows

## Motion

- Fast interaction response: 90–140 ms
- Panel entrance: 180–240 ms
- Large application transition: 240–320 ms
- Motion sequence: energize → scan → settle
- Honor reduced-motion preferences

## Sound

Sound cues must be optional, subtle, short, and categorized: navigation, confirm, warning, mechanical attachment, financial, and administrative.

## Accessibility

- Keyboard and controller navigation
- Visible focus states
- No information conveyed through color alone
- Scalable UI and safe-area support
- Contrast checked before release
